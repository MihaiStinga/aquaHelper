# aquaHelper

Aquarium water-parameter tracker for Android and the web. One codebase (Expo SDK 58, React Native, TypeScript), data stored locally in SQLite.

**Phase 1 (this version):** water parameters, ideal ranges (Low / Ideal / High), history, charts, CSV/PDF/JSON export and backup, calculated CO₂ and free ammonia. Next phases: water changes, checklists, rules and push notifications, fauna, Firestore sync. See the [plan](https://claude.ai/artifact/8yiNuXQPZ9nmo11mBpLkWC).

## Run locally

```sh
npm install
npm run web           # browser, http://localhost:8081/aquaHelper
npm run android       # needs Android Studio / SDK and a device or emulator
npm test              # domain unit tests
npm run typecheck
```

`expo-sqlite` on web needs `SharedArrayBuffer`. The dev server sends the required COOP/COEP headers (`metro.config.js`); the GitHub Pages build gets them from `coi-serviceworker` (`scripts/postexport-web.mjs`).

## Layout

| Path | What |
| --- | --- |
| `src/app/` | Screens (Expo Router). `(tabs)/` is the bottom navigation. |
| `src/components/` | UI pieces: cards, range bar, chart, dialogs. |
| `src/domain/` | Pure logic, no React: parameter catalogue, status, stats, chemistry, formatting, chart scale. Unit-tested. |
| `src/data/` | SQLite migrations, queries, in-memory store, export/backup. |
| `src/theme/` | Light and dark colours. |
| `.github/workflows/` | CI, web deploy, Android release. |

### Accuracy rules

- Values are stored exactly as entered (number + raw text) and rounded only for display, to each parameter's decimals (`src/domain/parameters.ts`).
- The chart draws only real readings at their real time: no zero-filled days, no smoothing, y-axis fitted to the data.
- CO₂ = 3 × dKH × 10^(7 − pH), computed for each pH reading with the latest KH from the 7 days before it (KH entered in ppm, 1 dKH = 17.848 ppm).
- Free ammonia uses the Emerson (1975) pKa with pH (≤ 3 h before) and temperature (≤ 24 h before). No partner reading in the window means no calculated value.
- Pairing windows live in `PAIR_WINDOW_MS` in `src/domain/chemistry.ts`.

### Adding a parameter

Add it to `PARAMETERS` in `src/domain/parameters.ts` and append a migration in `src/data/db.ts` that inserts its `parameter_setting` row. Never edit a migration that has shipped.

## Deploy

All three workflows run on GitHub Actions.

| Workflow | Trigger | Result |
| --- | --- | --- |
| `ci.yml` | every PR and push to `main` | typecheck, tests, web build |
| `android-ci.yml` | PRs touching dependencies or app/native config | Android APK build check |
| `web.yml` | push to `main` | web app on GitHub Pages at `https://<user>.github.io/aquaHelper/` |
| `android.yml` | tag `v*` (e.g. `git tag v0.1.0 && git push origin v0.1.0`) | signed APK attached to a GitHub Release |

### One-time setup

1. **Pages:** repository Settings → Pages → Source: **GitHub Actions**.
2. **Android signing:** create a keystore once and keep it safe; every future APK must be signed with it, or Android will not install the update over the existing app.

   ```sh
   keytool -genkeypair -v -keystore aquahelper.jks -alias aquahelper \
     -keyalg RSA -keysize 4096 -validity 10000
   base64 -w0 aquahelper.jks   # macOS: base64 -i aquahelper.jks
   ```

   On Windows (no `base64`), from cmd:

   ```
   powershell -NoProfile -Command "[Convert]::ToBase64String([IO.File]::ReadAllBytes('aquahelper.jks')) | Set-Clipboard"
   ```

   Add these repository secrets (Settings → Secrets and variables → Actions):

   | Secret | Value |
   | --- | --- |
   | `ANDROID_KEYSTORE_BASE64` | output of the `base64` command |
   | `ANDROID_KEYSTORE_PASSWORD` | keystore password |
   | `ANDROID_KEY_ALIAS` | `aquahelper` |
   | `ANDROID_KEY_PASSWORD` | key password |

3. **Install on the phone:** open the release on GitHub from the phone, download the `.apk`, and allow installs from the browser when Android asks.

Android builds compile only `arm64-v8a`, skip lint and cache native objects with ccache (`.github/actions/android-build`). The `android/` folder is generated by `expo prebuild` from `app.json` / `app.config.js` and is not committed.
